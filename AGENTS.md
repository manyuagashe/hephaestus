# AGENTS.md — worker contract for this repository

Read this before touching anything. It defines what "done" means here; a card that
claims success without satisfying this file is not done.

## Commands

Run from the repository root (in a worktree, that is the worktree root):

```bash
python3 -m unittest discover -s tests -t . -v   # definition of done
ruff check .                                     # lint (CI runs this too)
```

- Python 3.11+ standard library only. No new third-party runtime dependencies.
- `ruff` is optional locally; CI installs it. On the factory host it is already present
  at `~/.venvs/hephaestus/bin/ruff`. If it is missing, say so in your handoff
  rather than claiming lint passed.

## Rules

- Work only on files the card names. Do not reformat, reorder imports in, or "tidy"
  unrelated files — the diff is reviewed as a whole.
- Every behaviour change gets a test in `tests/` that fails before the change.
- Keep lines ≤ 100 characters.
- Public functions need a one-line docstring; no commented-out code.
- Never push to `main`. Work on the card's branch and open a PR.
- Never merge your own PR.
- If the card's acceptance criteria are ambiguous, ask via a card comment instead of
  guessing — a wrong guess costs a review round-trip.

## Definition of done

All of the following, evidenced in your handoff:

1. `python3 -m unittest discover -s tests -t . -v` exits 0 — paste the tail of the output.
2. `ruff check .` is clean, or the handoff states plainly that it could not be run.
3. The change is committed on the card's branch, and the handoff names the commit hash.
4. The handoff states what changed, what you verified, and what you did not.

## Branch and commit conventions

- Branch: `<project-slug>/<task-id>-<short-slug>` — `hephaestus/t_ab12cd34-add-rate-limiter`.
  `hephaestus.slug.slugify` / `hephaestus.slug.branch_name` implement the shortening rules.
- Commits: imperative subject, ≤ 72 characters, no emoji, no "generated by" trailers.
- One logical change per commit where practical.
